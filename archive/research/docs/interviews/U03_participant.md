# 인터뷰 U03 — 교내 취미 모임 참여자

## 문서 정보

- 참여자 ID: `U03`
- 참여자 유형: 오프라인 모임 참여자
- 주요 경험 플랫폼: 에브리타임 동아리 탭
- 참여 목적: 보유하고 있던 우쿨렐레를 다른 사람과 즐겁게 연주하기
- 인터뷰 일자·방식·시간: 2026-07-31, ZEP 화상 인터뷰, 15:00~15:05 (5분)
- 기록·녹음: 메모 기록 및 녹음 동의, 녹화 없음
- 익명화 상태: 실명·연락처 미기록
- 분석 상태: 메모 기반 요약 완료, 모집 주체와 활동 기간은 후속 확인 필요

## 1. 참여 배경과 발견 경로

U03은 이전부터 우쿨렐레를 가지고 있었다. 별도로 소모임을 탐색하던 중은 아니었지만,
에브리타임 동아리 탭에 올라온 모집 게시물을 보고 우쿨렐레 소모임에 참여했다.

이 사례에서 참여는 적극적인 검색보다 기존 관심사와 우연히 노출된 게시물이 맞물리며
발생했다.

## 2. 활동 경험과 만족

U03은 비슷한 성향의 사람들과 즐겁게 활동하기를 기대했고, 실제 경험은 이 기대에
대체로 부합했다고 평가했다. 모임 앱을 별도로 사용한 경험은 없어 서비스 간 직접 비교는
어렵다.

## 3. 모집 채널과 인원 부족

모임은 에브리타임에서만 사람을 구했고 총 3명이 활동했다. 대학 안에서 사람을 찾는
채널 특성상 추가 참여자 유입이 어려웠으며, U03은 인원이 더 모였다면 좋았을 것이라고
평가했다.

U03이 직접 모집을 담당했는지는 현재 메모만으로 확인되지 않는다. 따라서 이 사례는
개별 참여자의 모집 노동보다 **제한된 모집 채널이 모임 규모를 제약한 경험**으로 사용한다.

## 4. 후속 수요

U03은 코딩 모각코에 참여하고 싶었지만 적합한 모임을 찾지 못했다. 향후 자기계발 목적의
소모임을 찾을 수 있는 서비스가 있다면 사용할 의향이 있다고 답했다.

## 6. 분석 해석과 한계

- 활동 만족과 모집·발견 문제는 동시에 존재할 수 있다.
- 제한된 커뮤니티 채널은 관련성 높은 사람을 모으지만 충분한 규모를 만들지 못할 수 있다.
- 원하는 모임을 찾지 못한 이유가 실제 공급 부족인지 발견 기능 부족인지는 구분되지 않았다.
- 5분 인터뷰 메모를 바탕으로 정리했으며 직접 인용문으로 사용하지 않는다.
