# Synthesis Documents

`data/synthesis/`의 집계 데이터와 원문 카드를 사람이 읽을 수 있는 해석·의사결정 문서로
정리하는 영역이다.

## 문서 역할

- `insight_evidence_matrix.md`: 인사이트와 근거 강도
- `problem_definition_draft.md`: 검토용 문제 정의 초안
- `fishbone_raw_review_quotes_*.md`: Fishbone 원인별 리뷰 원문 연결

정량 수치의 원본은 `data/synthesis/`를 참조하고, 최종 제출용 문제 정의는 Notion 보고서와
인사이트 요약본을 기준으로 한다.
