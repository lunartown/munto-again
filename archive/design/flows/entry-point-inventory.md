# 문토 진입점 인벤토리

Sprint 1.5에서 문토의 콘텐츠 진입 경로를 빠짐없이 목록화하기 위한 문서입니다. 모든
경로를 독립적인 사용자 플로우로 분석하지 않고, 같은 목적지로 이어지는 경로는 대표
플로우로 통합합니다.

## 진입점 분류

`검색`, `카테고리`, `프로모션`, `찜`은 앱 밖에서 독립적으로 시작하는 지점이 아니다. 앱 진입 후
홈과 공통 탐색 영역에서 열리는 조작 표면이며, 각 목록 화면에도 검색·필터·정렬 조작이
반복된다. 따라서 플로우에서는 이들을 홈과 목록 화면의 자식 경로로 표시한다.

| 진입점 유형 | 캡처 | 도착 콘텐츠 | 현재 확인 내용 | 대표 플로우 |
|---|---|---|---|---|
| 홈·추천 | CS-01 | 소셜링·클럽·콘텐츠 큐레이션 | 여러 콘텐츠 유형이 한 화면에 함께 노출됨 | 콘텐츠 유형별 플로우로 분기 |
| 프로모션·큐레이션 | CS-02 | 특정 주제의 소셜링 목록 | 기간·주제 기반 목록으로 이동. 클럽·챌린지 홈에는 프로모션·큐레이션 섹션 자체가 없음을 직접 확인함 | 소셜링 전용 진입 |
| 카테고리 | CS-01 → CS-03 | 관심사별 목록 | 홈에서 카테고리 진입 후 선택 | 유형별 목록으로 분기 |
| 검색 | CS-01 → CS-04 | 키워드 검색 결과 | 홈에서 검색 진입 후 검색어 입력 | 유형별 목록으로 분기 |
| 소셜링 탭 | CS-01 → CS-10~24 | 일회성 모임 | 홈의 탭 또는 섹션에서 진입, 목록에서 검색·필터 가능 | 소셜링 참여 |
| 클럽 탭 | CS-01 → CS-30~41 | 장기 모임 | 홈의 탭 또는 섹션에서 진입, 목록에서 검색·필터·정렬 가능 | 클럽 가입·유지 |
| 챌린지 탭 | CS-60~62 | 챌린지 | 홈·상세·참여 진입 확인 | 챌린지 참여 |
| 찜 | CS-50 | 저장한 콘텐츠 | 찜한 목록으로 재진입 | 기존 콘텐츠 플로우로 합류 |

## 대표 플로우로 통합

```text
홈·추천·프로모션·카테고리·검색·찜
             ↓
     콘텐츠 목록 / 검색 결과
       ├── 소셜링 상세 → 신청·결제 → 신청·취소
       ├── 클럽 상세 → 가입 질문 → 대기·완료 → 채팅
       └── 챌린지 상세 → 참여
```

## 분석 범위 결정

- 진입점 인벤토리에는 네 가지 콘텐츠 유형을 모두 기록한다.
- Sprint 1.5의 상세 분석은 소셜링과 클럽을 우선 비교한다. 두 유형의 참여 목적과
  상태 변화가 다르기 때문이다.
- 챌린지는 구조를 확인하되, Sprint 2 대표 시나리오로 선택하지 않는다면 별도 개선안은
  만들지 않는다.
- 추천·프로모션·카테고리·검색은 독립 제품 플로우가 아니라 콘텐츠 목록으로 들어가는
  진입 표면으로 관리한다.
