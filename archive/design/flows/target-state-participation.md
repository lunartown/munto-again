# Target Flow — 클럽 가입 전 판단

> 상태: 범위 수정 중
> 목적: Current-State Audit에서 확인한 문제를 바탕으로 Sprint 2의 단일 핵심 시나리오를 정의한다.  
> 주의: 현재 상태를 확인하기 전에 해결안을 확정하지 않는다.

## 핵심 시나리오

> 클럽을 처음 고르는 사용자가 활동 목적·반복 방식·구성원 분위기·운영
> 규칙과 최근 활동 이력을 비교하고, 자신에게 맞는 클럽을 선택하거나 근거 있게 제외한다.

## 목표 흐름 초안

```text
클럽 탐색 → 후보 확인 → 활동 적합성 이해 → 지속성 판단 → 후보 비교 → 가입 결정
```

## 개선 대상

### 1차 대상

- 모임 목적과 실제 활동을 비교하기 어려운 문제
- 진행 방식·참가자 구성·음주·촬영·연령 조건이 흩어진 문제
- 최근 활동 빈도·활성 멤버·신규 참여 방식을 판단하기 어려운 문제

### 후속 대상

- 문제 발생 후 신고·환불·퇴출 처리
- 호스트 운영 포맷 입력과 운영 이력 관리

## Sprint 2 연결

  맞고 계속 참여할 클럽을 선택하거나 근거 있게 제외하고 싶다.
