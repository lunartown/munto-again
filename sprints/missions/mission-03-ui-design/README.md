# Mission 03 — 상세 UI 디자인

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

상태: 미션 2 와이어프레임 승인 대기

## 목표

승인된 IA와 와이어프레임을 기반으로 주요 화면을 완성된 UI로 발전시킨다. 화면 수를
늘리기보다 주요 사용자 플로우의 연결성과 상태 완성도를 우선한다.

## 필수 확인

- 홈·검색·프로필 등 과제에서 요구하는 주요 화면
- 핵심 플로우의 화면 간 연결
- Figma 스타일과 베리어블 활용
- 오토레이아웃 적용
- 재사용 UI의 컴포넌트·베리언츠 적용
- 수업 시간에 배운 기타 핵심 기능 활용
- 미션 2 UX Writing 반영
- 피드백 또는 리뷰 수정 기록

작업 링크와 프레임 상태는 `coursework/case-study/design/figma-index.md`에서 관리한다.
