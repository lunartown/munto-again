# Mission 09 — 문제 해결 장표 고도화

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

작업 정본: `coursework/portfolio/slides`와 Figma

- A안·B안 또는 기능 선택지를 선명하게 비교
- 장단점·고려 요소·최종 결정 이유 시각화
- 가능하면 Before/After와 개선 근거 포함
- 정량 결과가 있으면 정의와 출처를 함께 표시
- 빠진 맥락과 반복 슬라이드 점검
- 추가·생략한 내용과 이유 기록
- 기존 비주얼 규칙 유지
- 고도화한 문제 해결 장표 1~2개
- 추가·생략한 슬라이드와 이유를 담은 점검 메모

심화 선택으로 정량 성과를 추가하고 플로우차트, 비교표, 선택 트리, 타임라인 등 다양한
시각화 방식을 시도한다.
