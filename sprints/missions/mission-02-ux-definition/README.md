# Mission 02 — 시나리오·기능·IA·와이어프레임

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

상태: Sprint 1.5 현행 플로우 분석 대기

## 필수 산출물

- 주요 사용자 시나리오와 스토리보드: Figma
- JTBD 분석과 Job Statement: `product`
- 핵심 기능과 우선순위: `coursework/case-study/product/requirements`
- 정보 구조와 사용자 플로우: `coursework/case-study/design/flows`
- 핵심 화면 와이어프레임과 UX Writing: Figma
- 닐슨 10가지 사용성 기준의 휴리스틱 평가와 개선 방향: 선택 산출물

## 작업 순서

1. Sprint 1.5의 문토 Current-State Flow와 근거 매핑을 확인한다.
2. 상황·동기·기대 결과를 JTBD로 작성한다.
3. 하나의 주요 시나리오만 선택한다.
4. 기능 후보를 사용자 니즈와 직접 연결해 우선순위를 정한다.
5. IA보다 먼저 핵심 태스크 플로를 만든다.
6. 플로우를 지원하는 최소 IA와 와이어프레임을 제작한다.
7. 핵심 행동의 마이크로카피를 작성한다.
8. 휴리스틱 평가로 오류·상태·용어 문제를 수정한다.

## 완료 조건

- 기능마다 연결된 리서치 니즈가 있음
- 주요 시나리오가 하나로 수렴함
- Job Statement가 해결책을 포함하지 않음
- IA, 플로우와 와이어프레임의 화면이 서로 일치함
- 버튼·빈 상태·오류 안내의 UX Writing이 포함됨
- Figma 링크가 제출 레지스트리에 등록됨
