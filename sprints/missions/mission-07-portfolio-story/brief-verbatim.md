# Mission 07 원문 — 디자인 스토리와 포트폴리오 구성안

> 사용자 제공 미션 내용을 표현 수정 없이 구조만 Markdown으로 옮긴 보존본이다.

## 미션 요약

선별한 프로젝트 중 1개를 선택하여, '왜 이 문제였는가?' / '왜 이 방법을 썼는가?' / '어디서 배움이 있었는가?'를 중심으로 스토리를 작성합니다.
포트폴리오 콘텐츠 형태로 재구성하여, 각 섹션별 핵심 메시지와 시각 자료/텍스트 구분을 정리합니다.

## 요구사항

### 기본 요구사항

#### 디자인 스토리 작성

- 선별한 프로젝트 1개를 선택하여, 다음 질문에 답하는 형식으로 스토리를 작성합니다.
  - 왜 이 문제였는가?: 문제 발견 배경과 해결의 필요성
  - 왜 이 방법을 썼는가?: 디자인 의사결정의 근거와 대안 검토 과정
  - 어디서 배움이 있었는가?: 프로젝트를 통해 얻은 인사이트와 성장 포인트
- 각 질문에 대한 답변을 카드 또는 섹션 형태로 정리하여, 사고 과정이 명확히 드러나도록 구성합니다.

#### 포트폴리오 구성안 작성

- 선택한 프로젝트를 포트폴리오 콘텐츠 형태로 재구성합니다.
- 각 섹션마다 다음을 구분하여 정리합니다.
  - 전달하고자 하는 핵심 메시지
  - 이미지/시각 자료로 보여줄 내용
  - 텍스트로 설명할 내용
- 전체 구성은 인트로 → 핵심 요약 → 문제·해결 과정 → 결과·회고 순서를 따릅니다.

### 심화 요구사항 (선택)

- 독자 질문 기반 스토리 설계: 면접관이 궁금해할 질문을 예상하여, 그 질문에 답하는 형식으로 스토리 흐름을 재설계합니다.
- 예: "이 디자인을 왜 선택했나요?", "사용자 테스트 결과는 어땠나요?"

### 포트폴리오 구성안
