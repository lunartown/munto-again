# Mission 05 — 반응형·인터랙티브 프로토타입

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

상태: 미션 4 UI·컴포넌트 대기

## 필수 산출물

- 모바일과 데스크톱 등 최소 2개 브레이크포인트
- 화면 크기에 따른 그리드·오토레이아웃·콘텐츠 재배치
- 인터랙티브 컴포넌트 최소 2개
- 컴포넌트별 최소 2개 상태 전환
- 버튼·토글·스와이프 등 사용자 액션이 포함된 데모 플로우
- 각 뷰포인트의 Figma 미리보기 확인

## 심화 선택

- Galileo, Relume, Visily 등 AI UI 생성 도구 결과의 선택·수정 과정 기록
- 조건부 인터랙션
- Smart Animate 등 고급 전환

단순히 프레임 폭만 늘리지 않고 정보 우선순위와 입력 방식이 화면 크기에 맞게 바뀌는지
검증한다.
