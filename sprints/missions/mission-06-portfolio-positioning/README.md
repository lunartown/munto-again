# Mission 06 — 지원 목표와 포트폴리오 포지셔닝

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

작업 정본: `coursework/portfolio/strategy`

## 필수 산출물

- 관심 산업군·회사 유형·지원 포지션
- 실제 JD 1개 이상과 링크
- 필수 역량·우대 역량·업무 추출
- 여러 JD에서 공통으로 요구하는 보여줘야 할 역량 리스트
- 나를 대표하는 디자인 키워드 3개와 근거
- 프로젝트 목록과 선별 평가
- 포트폴리오 프로젝트 1개와 강조할 챕터

프로젝트는 문제 해결의 명확성, 주도성, 역량 증명 가능성으로 평가한다. 심화 선택으로
상위 역량 3개를 선정하고 그 이유와 프로젝트의 증명 장면을 연결한다.
