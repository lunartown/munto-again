# 소모임 — 인터뷰지

실제 진행용. 대괄호 코드는 검증 대상 가설(→ `interview-inventory.md`)이며 **참가자에게 읽지 않는다.** 코드 정의·판정 기준은 인벤토리 쪽이 정본이고, 여기는 순서대로 따라가는 진행 스크립트만 담는다.

★ 표시 3개는 **무조건 묻는다.** 나머지가 다 빠져도 이 3개는 못 빼먹는다 — A2↔A3(취미 목적인가 관계 목적인가)를 판정하는 유일한 도구이고, 직접 물으면 100% 부정당하는 질문이라 다른 방법이 없다. **세션 중에는 각각 따로 판정하지 않는다.** 순서상 §2·§4·§7에 흩어져 있지만, A2/A3 판정은 세션이 끝난 뒤 §8에서 세 개를 한 번에 놓고 같은 방향인지 확인한다. 하나만 보고 결론 내지 않는다.

---

## 0. 진행 원칙

- 말하기 20% / 듣기 80%. 침묵은 3초 기다린다
- 해석하지 말고 원문 그대로 적는다
- 앱이 이상하면 그건 앱 문제다. 도와주지 않는다 — 과업 중 길을 잃어도 그대로 둔다. 질문받으면 "저 없이 혼자 하셨으면 어떻게 하셨을 것 같아요?"로 되돌린다

**금지**
- "사람 만나려고 가시는 거예요?" / "얼마까지 내실 수 있어요?" (가정형은 가정형 답만 준다)
- "지난번에 ○○라고 하셨죠?" (그 순간 답이 고정된다)
- 우리가 뭘 만들지 설명 — 마지막 1분 전까지 금지
- 속성 이름(뒤풀이·나이·성비 등)을 우리가 먼저 꺼내는 것 — §5 전까지는 참가자가 스스로 꺼내게 둔다

## 1. 세션 전 (5분)

- 동의: "오늘 내용은 학습 프로젝트 안에서만 쓰고, 이름이나 알아볼 수 있는 정보는 다 빼고 정리할게요. 녹음해도 괜찮으실까요? 답하기 불편한 질문은 넘어가셔도 됩니다."
- 오프닝: "제가 만드는 거 얘기는 안 하고, 실제로 어떻게 하셨는지만 여쭤볼게요. **해당 없는 건 없다고 하셔도 됩니다.**"
- 앵커 판정 한 줄: "지금까지 실제로 나가보신 모임이 있으세요? 알아만 보고 안 가신 것도 포함해서요."
  - 있음 → 뒤에서 그 모임을 계속 회상 소재로 쓴다
  - 없음 → §4(경험 회고)는 건너뛰고 과업(§5) 위주로 진행한다

## 2. 사람과 동기 (15분)

- 평소 쉬는 시간엔 주로 뭐 하세요? `[A4]`
- 모임을 찾아야겠다고 생각한 계기가 뭐예요? 그 무렵 뭐가 달라졌어요? `[A1]`
- 그 활동, 친구랑 같이 하면 안 돼요? 왜 안 됐어요? `[B1~B3]`
  - ▷ 마지막으로 친구랑 같이 한 게 언제예요?
- ★**결정적 테스트 1** — 그 활동, 모임 없이 혼자 해보신 적 있어요? 최근에 언제, 얼마나 자주요? `[R1]`
  - 모임 있을 때만 함 = 활동은 수단(관계 목적 신호) / 혼자서도 꾸준히 함 = 활동 자체가 목적
- 모임 직접 만들어볼 생각 해보신 적 있어요? 왜 안 만드셨어요? `[D1~D4]`

## 3. 채널과 대안 (10분)

- 어디서부터 찾아보셨어요? 제일 먼저 떠오른 데는요? `[C6, C2]`
- 당근에 모임 기능 있는 거 아셨어요? 들어가 보신 적은요? `[C1, C3]`
  - 몰랐다 → 여기서 멈춤. 아셨다 → 그때 뭐 보고 나오셨어요?
- 인스타·카페·오픈카톡 같은 데는요? 왜 안 보셨어요? `[C7]`

---

## 4. 경험 회고 (앵커 있는 사람만, 10분)

- 좋았던 모임 경험 하나만 떠올려 주세요 — 뭐가 좋았어요? `[R28]`
- 반대로 실망스러웠던 경험은요? 뭐가 별로였어요?
- 그만둔 모임 있으면: ★**결정적 테스트 3** — 그때 그 모임 **활동 자체는** 어땠어요? `[R21]`
  - "활동은 괜찮았는데…"가 나오면 더 파고든다
- 가입만 하고 실제로 안 나간 모임 있어요? 왜요? `[H4]`

## 5. 과업 — 화면 탐색 (20분)

**지시문 (그대로 읽기)**
> "이제 실제로 하나 골라보실 거예요. 오늘 저녁에 진짜 가입한다고 생각하시고, 평소처럼 찾아서 하나 정하는 데까지 해주세요. 생각나는 대로 소리 내서 말씀해 주시고요. 제가 뭘 알려드리거나 평가하는 자리가 아니에요."

가입까지 실제로 진행해도 막지 않는다. 가입 화면에서 요구하는 정보(사진 등록 등)도 관찰 대상이다.

**과업 후 질문**
- 결국 왜 이걸 고르셨어요?
- 보다가 넘기신 모임들은 뭐 보고 넘기셨어요? (즉시 제외 사유)
- 앱 밖에서 더 찾아보고 싶으셨던 거 있어요? `[E7]` — 멘토 지목
- 호스트한테 물어보고 싶은 거 있었어요? 실제 물어보신 적 있어요? `[E6]` — 멘토 지목
- (왔다갔다 하신 게 보이면) 그때 뭘 비교하고 계셨어요? `[E8]` — 멘토 지목

**관찰 메모** (녹화 보면서 세션 후에 채워도 됨)
상세 진입 개수 / 10초 이내 이탈한 모임과 그때 화면에 보이던 정보 / 모임 간 왕복 횟수 / 앱 밖으로 나간 적 있는지, 뭘 검색했는지

## 6. 판단 기준 훑기 (10분)

먼저 자유 회상: "지금까지 보면서 뭘 기준으로 판단하셨어요? 생각나는 순서대로요." — **여기서 나온 항목·순서를 먼저 적는다.**
