# 인터뷰 기록 — 양나빈

참가자: 양나빈 / 진행자: 최명하
일시: 미확인 (기록 시점 기준 2026-08-14 이전, 정확한 날짜는 사용자 확인 필요)
앵커: 소모임 앱 미사용. 과거 실제 모임 경험은 대학 우쿨렐레 동아리(에브리타임 홍보 게시판을 통해 발견). 3년 전 오픈채팅 독서모임 시도 경험도 있음. 현재는 모임 가입 의사 없음 — 이후 질문은 "직장인이 되면"이라는 가정형 시나리오로 진행됨
세션 성격: 사전 인터뷰 + 소모임 앱 탐색 과업(화면 녹화, 영상은 별도 전달)

---

## 1. 배경 — 계기 없이 발견한 사례

- 우쿨렐레 모임 가입 계기: "동아리 뭐 할까" 하다가 에브리타임 홍보 게시판에서 소모임을 발견함. 특정 활동을 찾다가 간 게 아니라 "대학 내에서 동아리를 해야겠다"는 목표만 있었고 종목은 정해져 있지 않았음
- 우쿨렐레 자체는 초등학교 때 배우고 오래 방치돼 있던 것. 모임 가입 전에 혼자 다시 연습하거나 하지는 않았음

## 2. 미래 시나리오 (가정형 — 현재는 관심 없음)

- 직장인이 되면 배드민턴(활동적인 것)이나 독서 모임을 하고 싶다고 답함
- 목적 자기 보고: "친분을 쌓는다는 목적보다는 독서는 습관을 기른다는 목적, 배드민턴은 집에만 있으면 안 되니까." 커뮤니케이션을 특별히 좋아하는 편은 아니라고 덧붙임

## 3. 신뢰·안전

- 3년 전 독서 습관을 기르려고 오픈채팅방에 들어갔다가, 2주 정도 후 개인 연락이 와서 만났는데 다단계였던 경험이 있음
- 이후 모임을 볼 때 "유해하지 않은지", "순수하게 취미를 하는 곳인지", "활동이 주기적으로 되고 있는지"를 가장 먼저 본다고 답함
- 그 당시엔 오픈채팅방 외에 다른 채널은 떠올리지 못했다고 함

## 4. 결정적 테스트 관련 — 자연스럽게 걸림, 자기 보고와 방향이 다름

과업 전 대화에서 결정적 테스트 1·2에 해당하는 질문이 실제로 나왔고, 위 §2의 자기 보고와 다른 방향의 답이 나옴.

- **테스트 1 해당** — "평소에도 혼자 계속 하셨던 거예요?" → "아니요, 계속 안 하다가... 방치되어 있었는데 그때(모임 계기로) 하게 됐어요." 활동을 모임과 무관하게 혼자 지속한 이력이 없음. 활동은 수단 쪽 신호
- **테스트 2 해당** — "모임은 괜찮은데 사람들이 싹 다 바뀌면 그래도 나가실 거예요?" → "그게 양립할 수 없다고 생각해요. 모임이 사람들이 좋아야 의미가 있는 거고, 어차피 혼자 할 거면 혼자 하면 되니까." 질문의 전제 자체를 반박함. 활동과 사람을 분리해서 생각하지 않음 — 관계 쪽 신호
- 위 둘은 "친분 목적 아니다"라는 §2의 자기 보고와 반대 방향임. `interview-inventory.md` 원칙대로 A2/A3를 한쪽으로 확정하지 않고 혼합형·판단불가로 남김
- 테스트 3(그만둔 모임의 활동 자체 평가)에 해당하는 실제 이탈 경험은 없어 확인 못 함

## 5. 과업 — 소모임 앱 탐색

- think-aloud 발화가 텍스트로는 거의 남아 있지 않음("관심사 선택 화면이에요" 정도). 나머지는 별도 전달된 녹화 영상에 있을 가능성이 큼
- 하나를 골라 가입 직전까지 진행함(실제 가입 완료 여부는 불명확)

## 6. 판단 기준 — 자유 회상 후 항목별 확인

자유 회상 순서: 장소 → 개최 빈도 → (독서의 경우) 지정 도서 유무 → 인원(너무 적지 않은지) → 가입 인사 게시판에서 남녀 비율 → 연령대

항목별 임계값 확인:

| 항목 | 응답 |
|---|---|
| 연령대 | 20대 위주 선호 |
| 성비 | 남자 비율 높으면 부담 |
| 인원 규모 | 10명 이하는 별로, 30~40명 + 코어 인원 선호, 100명 이상도 별로 |
| 회비 | 있으면 꺼려짐. 월 5천원 이하면 고려 가능(본인이 학생이라는 전제) |
| 위치 | 30분 이내 |
| 최근 활동 게시글 | 활발히 운영되는지 확인 목적 |
| 참가자 실력대 | 배드민턴 급수 표기(A1 등)를 보고 무슨 뜻인지 몰랐다는 UX 이슈 언급. 독서는 실력대 자체가 불필요하다고 답함 |
| 반복 참석자 여부 | 말로는 "같은 사람이 계속 오는 게 오히려 좋다"(활동에 집중 가능)고 했는데, 본인이 직접 작성한 최종 분류표에는 "없어도 된다"로 적어 앞뒤가 다름. 원문 그대로 병기 |

**본인이 직접 작성한 최종 분류**
- 꼭 있어야 한다: 활동 종류, 연령대, 성비, 인원 규모, 회비, 위치·이동시간, 시작·종료 시간, 최근 활동 게시글, 참가자 실력대
- 있으면 좋다: 호스트 스타일
- 없어도 된다: 뒤풀이 유무, 같은 사람이 계속 오는지
