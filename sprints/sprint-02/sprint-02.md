## 와이어프레임 콘텐츠 결정

### 고정할 전제

36번 클럽 상세 화면을 가입 전 판단에 맞게 재구성하여, 사용자가 읽는 피로를 줄이고 필요한 정보를 빠르게 찾게 합니다.

### 먼저 정할 내용

호스트가 작성한 긴 소개글을 판단 기준별 정보로 구조화할지 결정합니다.

- 원문 유지형: 소개글은 유지하고 순서·글자 크기·강조만 개선
- 구조화형: 활동 방식·참여 조건·규칙 등으로 내용을 나누어 표시

두 안을 같은 실제 내용으로 비교한 뒤 구조화 여부를 결정합니다. AI 자동 생성이나 호스트 입력 화면은 구조화형을 선택한 다음 데이터 출처를 정할 때 검토합니다.

### 36번 자유 설명에서 확인되는 내용

설명 전체를 한 덩어리로 보지 않고, 다음 의미 단위로 나눠 읽습니다.

- 클럽 정체성·분위기: NF 성향, 감성적이고 따뜻한 공간이라는 설명
- 기대 경험: 서로의 결을 존중하고 깊이 있는 대화를 나누는 경험
- 함께할 사람: ENFP·ENFJ·INFP·INFJ 등 대상, 대화·배려·존중에 대한 기대
- 참여 제한: 선 넘는 장난, 대화 독점, 일방적인 관심·연락, 종교·영업·개인 홍보,
  클럽 분위기를 해치는 행동
- 활동 내용: 대화, 전시·책·사진·동네 탐색 등 관심사를 함께 나누는 활동
- 운영·식별 정보: `Since 2025.06`, 해시태그

### 기존 정보의 1차 배치안

자유 설명의 구조화 여부와 관계없이, 현재 화면의 블록은 다음 순서로 재배치해 비교합니다.

1. **클럽 기본 정보**
   - 배너, 프로필 이미지, 클럽 이름, 호스트
   - 지역, 소셜링 수, 피드 수, 인원/정원, 최근 대화 시점
2. **클럽 설명**
   - 현재 자유 설명을 하나의 블록으로 유지
3. **가입 판단 조건**
   - 카테고리, 승인제 여부, 운영비, 운영비 사용처, 연령대, 상세 위치
4. **실제 활동 확인**
   - 클럽 소셜링 목록, 클럽 피드
5. **구성원 확인**
   - 가입 멤버 미리보기와 더보기
6. **추가 확인**
   - 댓글, 비슷한 클럽
7. **신청하기**
   - 하단 고정 버튼 유지

이 순서는 ‘무슨 클럽인지 파악 → 가입 조건 확인 → 실제 활동 확인 → 추가 탐색’의 판단 흐름을
기준으로 한 1차안이며, 자유 설명을 항목별로 나누는 문제와는 별도로 먼저 검토합니다.

### 참가자 질문과 현재 화면의 아쉬움

| 참가자가 알고 싶은 것 | 현재 화면에서 확인되는 정보 | 현재 화면의 아쉬움·검토 가설 |
|---|---|---|
| 이 클럽은 정확히 무엇을 하는가? | 자유 설명, 클럽 소셜링, 클럽 피드 | 설명이 자유로운 긴 글이라 핵심을 빠르게 찾기 어려울 수 있음 |
| 어떤 분위기와 사람을 기대하면 되는가? | 함께할 사람·가입하지 말아야 할 사람에 대한 설명 | 대상과 제한 조건이 설명 안에 섞여 있음 |
| 실제로 어떤 활동을 하는가? | 클럽 소셜링 목록, 클럽 피드 | 활동 목록·게시물·설명이 서로 다른 구간에 있음 |
| 지금도 활발하게 운영되는가? | 소셜링 수·피드 수·최근 대화 시점, 소셜링 목록·피드 | 수치와 게시물의 시점·주기를 함께 봐야 판단할 수 있음 |
| 가입하면 어떤 조건을 감수해야 하는가? | 비용·운영비 사용처·연령·지역·승인제 여부 | 안내사항 구간에 모여 있어 앞의 설명과 함께 비교해야 함 |
| 나와 맞는 클럽인지 빠르게 판단할 수 있는가? | 위 정보 전체 | 판단에 필요한 정보가 소개·활동·안내사항으로 나뉘어 있음 |

위 표의 마지막 열은 확정된 문제 목록이 아니라, 현재 화면 관찰과 리서치 근거를 연결해 검토할 가설입니다.

### 2026-08-05 — 자유 설명과 ‘분위기’ 구체화

‘분위기’라는 표현을 그대로 정보 항목으로 사용하지 않고, 참가자가 실제로 알고 싶은 질문과
관찰 가능한 데이터로 나눴습니다.

| 참가자가 궁금한 것 | 구체적으로 확인할 내용 | 현재 확인 가능한 출처 | 정보의 성격 |
|---|---|---|---|
| 무엇을 하는 모임인가 | 주된 활동, 소셜링 주제, 활동 사진·게시물 | 자유 설명·클럽 소셜링·클럽 피드 | 호스트 설명 + 활동 기록 |
| 사람들은 어떻게 어울리는가 | 깊은 대화인지, 자유 대화인지, 정해진 진행이 있는지 | 자유 설명·소셜링 내용·참여자 반응 | 호스트 주장과 실제 경험을 구분해야 함 |
| 어떤 사람이 잘 맞는가 | 대상이 되는 사람, 기대하는 태도·관심사 | 자유 설명·카테고리·멤버 정보 | 호스트가 제시한 기준 |
| 무엇을 불편해하는가 | 대화 독점, 선 넘는 장난, 홍보 등 금지 행동 | 자유 설명 | 운영 규칙·호스트 기준 |
| 실제로 어떤 반응이 나오는가 | 게시물 내용, 댓글, 참여자 후기·평가 | 클럽 피드·댓글·추후 참여자 경험 기능 | 참여자 경험 근거 |

따라서 상단 요약 카드에 ‘분위기’라고 쓰는 대신, 위 질문 중 실제 데이터가 있는 항목을
짧게 보여줘야 합니다. 호스트의 주장만 있는 항목과 참여자 활동으로 확인되는 항목도
구분해야 합니다.

#### 이 내용과 연결되는 사용자 판단 니즈

- 이 클럽이 어떤 목적과 분위기의 모임인지 빠르게 알고 싶음
- 내가 함께하기에 맞는 사람·태도인지 판단하고 싶음
- 가입 전에 지켜야 할 조건과 피해야 할 행동을 확인하고 싶음
- 설명의 기대와 실제 활동이 어느 정도 연결되는지 가늠하고 싶음
