# 인터뷰 기록 — 김다인

참가자: 김다인 / 진행자: 최명하
일시: 미확인 (기록 시점 기준 2026-08-14 이전, 정확한 날짜는 사용자 확인 필요)
앵커: A(참석형) — 당근 모임(수영 등) 실제 참석 경험 있음. 소모임 앱은 설치 경험 있음
세션 성격: 재인터뷰(2회차로 추정, "지난번 시간 내주셨는데" 발화 근거). 사전 인터뷰 + 소모임 앱 탐색 과업(화면 녹화)으로 구성

과업 후 판단 기준 질의 구간은 녹음이 유실되어, 아래 §4는 진행자가 세션 중·직후 작성한 메모를 근거로 정리했습니다. 원문 표현이 축약된 부분은 그대로 인용 표시했습니다.

## 1. 모임을 찾는 동기

- 평소엔 혼자 하는 활동 위주(독서, 운동, 피그마/디자인 스터디 등 자기계발 성격)
- 혼자 할 때는 강제성이 낮아 지속이 어렵다고 느껴, 모임을 통해 강제성을 얻으려 함
- 함께할 때 시너지(정보 공유, 바디더블링 등)를 기대함
- 본인 스스로는 "사교 자체가 목적은 아니다"라고 진술 (자기 보고)

## 2. 친구 대신 모임을 택하는 이유

- 친구들은 대부분 직장인이라 시간 맞추기 어렵고 관심사도 다름
- 이미 그 활동에 익숙한 사람과 함께 하는 편이 더 편하고 배울 점도 있다고 느낌
- 모르는 사람과의 약속이라 "지킬 수밖에 없다"는 강제성이 생김
- 모임 종료 후 멤버 간 간단한 후기(부/부정) 작성 절차가 있고, 이 존재 자체가 "쾌적하게 유지하려는 마지노선"처럼 작동한다고 언급 (본인이 평가를 크게 의식하는 건 아니라고 덧붙임)

## 3. 탐색 채널

- 당근을 가장 먼저 떠올림 — 이동 거리를 싫어해 동네 기반 서비스를 선호, 이미 당근을 자주 써서 앱 내 광고(탭)로 모임 기능을 인지
- 인스타/카페는 고려 안 함 — 카페는 "연령대 높고 올드하다"는 인상, 인스타는 "로맨스/소개팅 성격이 강하다"는 인상 (본인 고정관념이라고 스스로 밝힘)
- 당근 외 다른 동네 커뮤니티 채널은 떠올리지 않았다고 답함

## 4. 직접 개설을 고려했던 경험

- 기존 당근 수영 모임에서 불편한 멤버(헤비 유저, 대화 스타일 안 맞음)를 계속 마주치는 것 + 거리 이동 부담이 겹쳐 "가까운 수영장 모임을 직접 만들까" 생각함
- 실행 직전 더 가깝고 소규모인 다른 모임을 발견해 그쪽으로 옮기며 개설은 실행하지 않음
- 옮긴 모임에서도 방장이 약속을 지키지 않아 탈퇴함

## 5. 좋았던 경험 / 실망스러웠던 경험

- 좋음: 멤버가 친절할 때(당근에서 만난 사람들은 대체로 친절했다고 평가, 당근을 계속 쓰는 이유로 언급), 본인보다 스킬·경력이 높은 사람에게 배울 점이 있을 때(수영 선수 출신 멤버 사례)
- 실망: 모임의 원래 목적이 흐려질 때(운동 모임인데 뒤풀이·친목이 중심이 되는 경우), 목적에 안 맞는 대화, 반가움을 과하게 티 내는 사람

## 6. 앱 탐색 시 겪은 어려움 (당근 기준)

- 당근이 전국 서비스로 확대되며 자신의 동네가 아닌 먼 지역(예: 종로구) 모임이 노출됨 — 당근의 원래 정체성(동네 기반)과 안 맞고 본인의 최우선 기준(거리)과도 어긋난다고 느낌
- 모임이 실제로 활발히 운영 중인지 판단하기 어려움 — 가입 인원은 있는데 채팅방이 비어 있는 "유령 모임"이 존재. 개설이 쉬운 만큼 유령 모임도 많다고 느낌
- 반면 카테고리 분류는 잘 되어 있어 목적별 탐색 자체는 쉽다고 평가
- 모임 선택 시 가입자 후기를 참고한다고 답함. 당근은 일정 후기를 쓰면 그 모임의 순위가 올라가는 구조가 있다고 설명함(후기 작성 유인 메커니즘)
- 모임이 활발한지 판단할 때 "몇 개의 일정을 진행했는지"(히스토리)를 확인한다고 언급

## 3부. 과업 — 소모임 앱 탐색 (화면 녹화 + think-aloud)

과업 범위: 처음 탐색하는 사람으로서 모임을 찾아 둘러보고, 가입을 결심하는 단계까지 (실제 가입 여부는 참가자 자유 선택)

### 관찰된 행동·발화

**온보딩 — 관심사 선택**
- 앞서 관심사를 몇 개 선택했는데, 다음 화면에서 카테고리 수가 갑자기 크게 늘어나 "내가 선택한 게 반영이 안 된 것 같다"고 느낌
- 화면 밀도가 급격히 올라가는 데 당황함

**목록·탐색 화면**
- "더보기"로 봤던 항목이 다른 섹션에서 다시 나오는 것에 의아함 표시("이럴 거면 왜 더 보기로 한 거야?")
- 방 제목에 이모지가 많은 모임을 보고 복잡하다고 느끼며 부정적으로 평가
- "내 지역 만들기" 기능을 처음엔 "더보기"로 오인함. 지역을 선택했는데도 자신의 동네가 안 뜨는 것에 대해 "아까 지역 선택을 왜 한 거야?"라고 의문 제기 — 필터가 실제로 반영되는지 확신하지 못함
- 특정 모임 상세에서 실력 조건("선출이면 좋은데 팀 애송이라서", "고연차는 안 받네") 문구를 직접 확인하는 행동 관찰됨
- 패들보드처럼 진입장벽이 있는 활동은 "아는 사람이 있으면 탐색 비용이 줄어든다"고 긍정 평가
- 스크랩(찜) 기능을 사용함. 찜 시 뜨는 바텀시트의 추천 모임이 본인과 안 맞고 비슷한 추천이 반복돼 무시하게 됨. 바텀시트가 화면 대부분을 차지할 만큼 크고 정보량이 많아 "빨리 닫고 싶다"고 느낌
- 전반적으로 화면 밀도가 높아 "뭘 눌러야 이동되는지", "이게 모집글인지 아닌지"조차 판단하기 어려웠다고 함
- 러닝 모임에서 "마라톤에 진심인 분들, 초보도 환영"처럼 제목과 실제 성격이 안 맞아 보이는 사례를 부정적으로 언급함
- 마지막으로 본 모임에서는 최근 활동 게시글이 잘 보였고, 그 아래 바로 정기모임의 D-1/D-2 표시가 직관적이어서 좋았다고 긍정 평가함
- 최종적으로 한 모임을 선택해 가입을 시도했고, 프로필 사진 등록을 요구하는 단계에서 과업을 종료함

### 과업 후 인터뷰 — 탐색 시 느낀 점

- "입력했던 관심사 정보가 반영 안 되는 느낌"이 가장 불편했다고 재확인. 정보를 입력하는 과정 자체를 허들로 느끼는데, 그 입력이 결과에 반영되지 않으니 이중으로 불편했다고 설명
- 정렬 기준이 모호함을 지적 — 동네 기준도 아니고 목적별 기준도 아니고 섞여 있어 보기 불편했다고 함
- 카테고리 분류 자체는 "앱 내부 정리용"이지 "개인 맞춤화"는 아니라고 평가. 대안으로 "관심 카테고리만 선택하게 하거나, 아예 입력을 없애는 편이 낫다"는 의견 제시
- 찜 → 바텀시트 추천이 안 맞고 반복적이라 무시하게 됐다는 점 재언급
