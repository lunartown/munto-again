# Somoim Design System

소모임 후기 프로토타입에 실제로 사용된 토큰과 컴포넌트를 먼저 문서화하는 React 사이트입니다.

## 정보 구조

- `/` — 문서 범위, 원본 링크, 문서 상태
- `/foundations` — 컬러, 타이포그래피, 간격, 반경, 그림자, 아이콘
- `/components` — 핵심 컴포넌트와 보조 컴포넌트 인벤토리, 프로토타입 사용 맵
- `/components/[slug]` — Anatomy, Variants, States, Usage, 보강 필요 항목
- `/roadmap` — 현재 공백과 단계별 확장 순서

## 1차 상세 문서 범위

- Participated Gathering Card
- Textbox
- Review Item

컴포넌트 개수를 채우기보다 Figma 프로토타입에서 반복 사용되고 상태가 확인된 요소를 우선했습니다. Figma에서 확인된 사실, 문서화를 위한 선택, 아직 확인되지 않은 정책을 서로 다른 상태로 표시합니다.

## 실행

```bash
npm install
npm run dev
npm run build
```
