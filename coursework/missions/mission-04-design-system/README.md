# Mission 04 — 소규모 디자인 시스템

[사용자 제공 미션 원문 전체 보기](brief-verbatim.md)

상태: 미션 3 상세 UI 대기

## 필수 산출물

- 브랜드 또는 프로젝트 컬러 토큰
- 타이포그래피: 폰트·크기·자간·행간
- 아이콘 사용 규칙
- 버튼·카드·리스트 중 최소 2개 컴포넌트 문서화
- 기본·호버·클릭·비활성 등 상태
- 컴포넌트 구성 요소와 사용 예시
- 각 스타일 또는 컴포넌트의 사용 가이드 최소 1개

심화 선택으로 팝업 모달, 토글, 날짜·시간 선택기 등 추가 컴포넌트와 다양한 상태를
문서화할 수 있다.

실제 화면에서 반복되는 요소를 먼저 컴포넌트로 승격한다. 제출 개수를 채우기 위해 사용하지
않는 컴포넌트를 만들지 않는다.
