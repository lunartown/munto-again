# Mission 02 원문 — 시나리오·기능·IA·와이어프레임

> 사용자 제공 미션 내용을 표현 수정 없이 구조만 Markdown으로 옮긴 보존본이다.

## 미션 내용

스프린트 2 미션에서는 리서치 인사이트를 바탕으로 사용자 시나리오와 스토리보드를 작성하고, 핵심 기능을 정의합니다. 이를 정보 구조(IA)와 사용자 플로우차트로 구체화한 후, 와이어프레임을 제작하고 UX Writing을 적용해 사용성을 개선합니다.

## 요구사항

### 기본 요구사항

- 스프린트 1에서 도출한 리서치 인사이트를 토대로 하나의 주요 사용자 시나리오와 스토리보드를 작성하며, 이 시나리오를 중심으로 핵심 기능을 정의합니다.
- 정의한 기능을 정보 구조(IA)와 플로우차트로 구체화하여 사용자 흐름을 명확히 표현하고, 이를 바탕으로 와이어프레임을 제작합니다.
- Jobs to be done 분석과 Job Statement 작성 실습을 통해, 사용자가 서비스에서 해결하고자 하는 문제와 의도를 구체적으로 기술합니다.

### 심화 요구사항

- 사용성을 고려한 UX Writing 전략을 적용하여, 와이어프레임 내 핵심 화면에 적합한 마이크로카피(버튼 텍스트, 안내 문구 등)를 작성합니다.
- 닐슨의 10가지 사용성 평가 기준을 활용한 휴리스틱 평가를 실시하여, 초안 와이어프레임 상의 사용성 이슈를 식별하고 개선 방향을 제안합니다.

### 스토리보드 및 사용자 시나리오

- 형태: 그림 또는 시각적 흐름도 Figma
- 내용:
  - 주요 사용자 시나리오
  - 사용자 경험의 단계별 흐름과 맥락 시각화

### 기능 정의 문서

- 형태: 문서 또는 표 형식
- 내용:
  - 서비스의 핵심 기능 및 기능 우선순위
  - 기능과 사용자 니즈 간의 연계성 설명

### 정보 구조(IA) 및 플로우차트

- 형태: 다이어그램 Figma
- 내용:
  - 정보 구조 설계(IA)
  - 사용자 플로우의 단계별 흐름 정리

### 와이어프레임 + UX Writing 초안

- 형태: Figma
- 내용:
  - 서비스 핵심 화면 와이어프레임 제작
  - 버튼 텍스트, 안내 문구 등 마이크로카피 작성

### (Option) 휴리스틱 평가 보고서

- 형태: Notion
- 내용:
  - 닐슨의 10가지 사용성 평가 기준에 따른 와이어프레임 검토
  - 사용성 문제점 및 개선 방안 제시
