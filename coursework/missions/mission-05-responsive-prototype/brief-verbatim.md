# Mission 05 원문 — 반응형·인터랙티브 프로토타입

> 사용자 제공 미션 내용을 표현 수정 없이 구조만 Markdown으로 옮긴 보존본이다.

## 미션 요약

반응형 디자인 원칙과 인터랙티브 컴포넌트 제작 기술을 활용하여, 모바일, 태블릿, 데스크톱 등 다양한 화면 크기에 대응할 수 있는 반응형 레이아웃을 설계하세요.
2개 이상의 인터랙티브 컴포넌트(예: 버튼, 토글, 모달 등)를 제작하고, 상태 전환(기본/호버/클릭/활성화 등)을 정의하여 사용자 인터랙션을 시뮬레이션할 수 있는 프로토타입을 완성하세요.

## 요구사항

### 기본 요구사항

#### 반응형 디자인 적용

- 모바일, 태블릿, 데스크톱 등 최소 2개 이상의 브레이크포인트를 설정하고, 기기별로 레이아웃이 어떻게 재배치·재구성되는지 Figma 프레임으로 제작해 주세요.
- 필요 시 콘텐츠(이미지, 텍스트, 버튼 등)가 화면 크기에 따라 유연하게 변화하도록 설계합니다.

#### 인터랙션 디자인 & 인터랙티브 컴포넌트 구현

- Figma 인터랙티브 컴포넌트(Variants 등)를 활용해, 컴포넌트 상태(예: 기본/호버/클릭, 열림/닫힘 등)를 정의하고 프로토타입에서 실제 동작을 확인할 수 있게 만듭니다.
- 2개 이상의 인터랙티브 컴포넌트(예: 버튼, 모달, 토글, 스와이프 가능한 슬라이드 등)를 생성해 보세요.

#### 프로토타입 데모 제작

- 반응형 레이아웃과 인터랙티브 컴포넌트가 결합된 프로토타입을 만들어, 간단한 사용자 흐름(예: 버튼 클릭 → 화면 전환, 스와이프 → 다음 슬라이드 등)을 시연할 수 있게 합니다.
- 데스크톱, 모바일 등 각각의 뷰포인트에서 어떻게 동작하는지 Figma 미리보기를 통해 확인할 수 있어야 합니다.

### 심화 요구사항

#### AI를 활용한 UI 생성 툴 사용

- Galileo, Relume, Visily 등 AI 기반 UI 생성 도구 중 하나를 활용해, 특정 화면(예: 회원가입, 메인 대시보드 등)을 자동 생성하거나 와이어프레임을 만들어 본 뒤, 이를 Figma 프로토타입에 접목해 보세요.
- AI로 생성한 결과물을 그대로 가져오기보다는, 필요한 부분만 선택·수정하여 프로젝트에 맞게 최적화하는 과정을 거치면 좋습니다.

#### 고급 인터랙션

- 조건부 인터랙션(예: 특정 조건을 충족해야 다음 화면으로 이동 가능)이나, 애니메이션(Smart Animate 등)을 이용해 한층 더 풍부한 프로토타입을 시도해 보세요.
- 예: 토글 스위치가 켜졌을 때만 특정 컴포넌트가 활성화되어 다음 단계로 이동할 수 있도록 설계

- 형태: Figma
- 내용:

### 반응형 레이아웃 예시

- 최소 2개 이상의 화면 크기에 대한 프레임(모바일, 데스크톱 등)을 Figma에서 구성
- 실제 레이아웃 재배치가 어떻게 이뤄지는지(그리드, 오토레이아웃, 브레이크포인트 등) 확인 가능해야 함

### 인터랙티브 컴포넌트

- 2개 이상의 컴포넌트에 대해 Interactive Components 기능 사용
- 기본, 호버, 클릭, 활성/비활성 등 최소 2가지 이상의 상태 전환

### 프로토타입(데모)

- 반응형 디자인 + 인터랙티브 컴포넌트가 결합된 프로토타입
- 버튼 클릭, 스와이프, 토글 등 사용자의 액션에 따라 화면이 전환되거나 컴포넌트 상태가 바뀌는 시연
