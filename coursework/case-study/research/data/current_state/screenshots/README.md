# 문토 현재 상태 화면 캡처

Sprint 1.5 현재 상태 플로우 분석을 위한 화면 증거 자료입니다. 이미지 자체는 편집하지
않고, 파일명과 이 목록으로 화면의 역할을 관리합니다.

## 파일명 규칙

```text
[번호]-[제품 유형 또는 진입점]-[화면 역할].[원본 확장자]
```

- `01~09`: 홈·추천·공통 진입점
- `10~29`: 소셜링 탐색·상세·참여·취소
- `30~49`: 클럽 탐색·상세·가입·채팅
- `50~59`: 찜·개인화 기능
- `60~69`: 챌린지 구조 확인
- 원본 이미지 형식은 유지하고 확장자만 소문자로 통일합니다.

## 추가 확보가 필요한 화면

- 소셜링 참여 후 실제 참석·체크인 상태
- 검색 결과에서 챌린지·피드 탭 결과 화면
- 클럽 채팅방의 "소셜링" 탭·"클럽 피드" 내부 화면 (지금은 채팅 문구로만 존재 확인)
- 클럽 탈퇴 시 경고 점수·환불 정책 (CS-42에서 "참여 취소" 버튼 존재만 확인됨)
- 비승인제 소셜링 사례 (신청 완료 캡처가 CS-21 하나뿐이고 승인제였음 — 클럽처럼 두
  버전이 다 있는지 미확인)
- 챌린지의 승인 대기·자동취소·거절·대기취소 실제 화면 (소셜링·클럽 패턴으로 추론만
  해뒀고, 챌린지 전용 캡처는 없음 — 가장 우선순위 높은 다음 캡처)
- 소셜링·챌린지 참여자 목록(CS-17/CS-61)에 클럽 "가입 멤버"에도 팔로우 버튼이 있는지

## 해결된 항목 (2026-08-02 추가 캡처로 확인)

- 소셜링 승인 완료 후 채팅방 자동 생성과 진입 경로 → CS-25, CS-42
- 소셜링 확정 후 취소 시 경고 점수·환불 티어 → CS-26 (대기 중 취소는 CS-22에 이미 있었음)
- 클럽·챌린지 홈에는 프로모션·큐레이션 섹션이 없음 (소셜링 전용) → CS-30, CS-60 직접 확인
- 모임내역의 `진행중` 구획은 참여자 상태가 아니라 호스트로 개설한 모임 목록임을 확인함
  (CS-05 빈 상태 문구 "내가 진행하는 소셜링은 여기에서 확인할 수 있어요"). 참여자 우선
  여정과 무관해 더 이상 확인 대상이 아님
- 클럽도 승인제 존재. "승인제 클럽은 신청 후 24시간 내 미승인 시 자동취소·활동비 전액환불"
  문구를 가입 대기 화면에서 확인함 → CS-39 (소셜링과 동일 구조)
- **비승인제 클럽도 실제로 존재.** 가입 질문 제출 직후 대기 화면 없이 바로 "클럽 참여가
  완료됐어요!"로 끝난 사례 확인 → CS-40. 클럽마다 승인 여부가 다르다는 것이 가정이 아닌
  사실로 확정됨
- 클럽 가입 화면에 호스트의 명시적 거절 가능성과 "합류 후 공지 이행" 조건 확인 → CS-37
- 가입 질문 형식이 클럽마다 다름(자유 서술 vs 특정 포맷·연령 자격 요건) → CS-37, CS-38
- **클럽의 "정기 일정·활동 참여 상태" 해결.** 채팅방 안에 별도 "소셜링" 탭이 있고, 일정
  변경 공지가 채팅으로 오간다. "클럽 피드"로 활동 사진도 공유함 → CS-41
- 클럽 검색 정렬에 "클럽 소셜링 많은 순"이 있어 클럽↔소셜링 연결이 핵심 기능임을 확인 →
  CS-35
- 클럽 카테고리·온라인 필터 구성이 소셜링과 동일 → CS-32, CS-34
- 챌린지도 승인제이고 무료 챌린지도 있음 → CS-61
- **유료 클럽의 실제 결제 화면 확인됨.** 소셜링과 동일하게 가입 질문 답변 다음,
  승인 여부 결정 전에 "결제·환불 확인" 단계가 있음 (직접 확인, 사용자 제보)
- **소셜링도 무료인 경우가 있음.** CS-26에서 결제·환불 금액이 모두 0원인 사례 확인
- **챌린지의 "완료·인증 상태" 해결.** 매일 인증(사진 업로드)으로 진행되고, 기간 종료 후
  실제 오프라인 "티타임" 모임으로 마무리됨. 가입 질문도 이 모임을 전제로 구성돼 있음 →
  CS-61, CS-62
