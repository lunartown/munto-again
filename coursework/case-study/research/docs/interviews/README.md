# 인터뷰 인덱스

실명 대신 역할 기반 익명 ID를 사용한다. 개별 문서에는 사실·행동·인식·해석·미확인을
분리하고, 인터뷰 간 가설과 반례를 연결한다.

| ID | 역할 | 핵심 사례 | 결과 | 문서 |
|---|---|---|---|---|
| H01 | 전문 모임 주최자 | 콘텐츠·관계 노동 집중 | 수요가 있어도 재개설 보류 | [보기](H01_host.md) |
| U01 | 취미 모임 참여자 | 활동·장소·공동 일정이 구조화된 수영 모임 | 약 1년 참여 추정, 후속 확인 필요 | [보기](U01_participant.md) |
| HU01 | 참여자 겸 친목 모임 운영자 | 문제 행동·재가입·안전 대응 부담 | 약 2년 운영 후 중단 | [보기](HU01_participant_host.md) |
| U02 | 친구 관계 목적 참여자 | 구조 없는 다인 친목 모임 | 1회 참여 후 중단, 1대1 서비스로 이동 | [보기](U02_participant.md) |
| HU02 | 그림·언어교환 참여자 겸 운영자 | 소규모 포맷·규칙을 직접 설계, 문제 참가자 퇴출 | 현재 반복 운영 중 | [보기](HU02_participant_host.md) |

## 현재 표본

- 인터뷰 완료·요약: 5건
- 역할: 주최자 3명 경험 포함, 참여자 4명 경험 포함
- 목표: 최소 6건
- 다음 우선 대상:
  1. 전문·학습 모임을 중단한 다른 주최자
  2. 문제 행동을 플랫폼 신고·지원으로 해결해본 주최자 또는 반례 참여자

## 현재 비교 축

- 활동 구조가 강한가, 자유 대화에 가까운가
- 고정 장소가 있는가, 매번 조율해야 하는가
- 다인 모임인가, 1대1 또는 소그룹인가
- 운영 노동이 모임장에게 집중되는가, 구성원이 나누는가
- 문제 행동과 안전 대응을 플랫폼이 지원하는가
- 관계가 플랫폼 안에서 지속되는가, 외부로 이동하는가
