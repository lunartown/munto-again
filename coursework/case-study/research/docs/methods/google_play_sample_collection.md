분석 표본은 최신순 원자료에서 1~3점 리뷰 50건과 4~5점 리뷰 15건을 각각
순서대로 선정했다. 고평점 표본은 부정 리뷰에서 발견한 패턴의 반례를 확인하기 위한
것이며 전체 만족도 비율을 추정하는 용도가 아니다.

## 수집·보호 원칙

- 공개된 리뷰 본문, 별점, 작성 시각, 공감 수, 앱 버전만 저장했다.
- 작성자 이름, 프로필 이미지, 개발자 답변은 저장하지 않았다.
- 리뷰 ID는 중복 제거와 재현성 확인 용도로만 사용한다.
- 분석 카드에는 원문 전체를 복제하지 않고 짧은 인용과 연구자 요약을 분리한다.

## 품질 확인

- 원자료 120건과 표본 65건 모두 리뷰 ID 중복 없음
- 평점 범위, 날짜, 본문 필수값 검증 통과
- 표본 구성: 저평점 50건, 고평점 15건 확인
- 이번 최신순 표본은 모두 2025~2026년 자료이므로 2021~2024년과의 시간축 비교에는
  별도의 과거 리뷰 수집이 필요함

## 해석 한계

앱 리뷰는 자발적으로 글을 남긴 사용자에 편중되고 최신순 표본은 전체 사용자나 전체
리뷰를 대표하지 않는다. 따라서 결과는 불편 유형과 후속 인터뷰 질문을 찾는 탐색
자료로 사용하고, 불만 사용자 비율이나 인과관계의 근거로 사용하지 않는다.
