# Current Flow — Evidence Matrix

반복 근거와 실제 화면 확인을 섞지 않고 각각의 출처를 구분한다.

## 판정 규칙

- `확인됨`: 현재 화면과 사용자 근거가 모두 있음
- `부분 확인`: 한 자료 또는 일부 화면에서만 확인됨
- `가설`: 연구자가 연결한 설명이며 직접 근거가 부족함
- `미확인`: 현재 화면 또는 근거가 아직 수집되지 않음
