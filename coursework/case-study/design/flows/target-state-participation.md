# Target Flow — 참여 전 모임 선택

> 상태: Sprint 1.5 이후 작성  
> 목적: Current-State Audit에서 확인한 문제를 바탕으로 Sprint 2의 단일 핵심 시나리오를 정의한다.  
> 주의: 현재 상태를 확인하기 전에 해결안을 확정하지 않는다.

## 핵심 시나리오

> 처음 참여하는 사용자가 모임의 운영 약속을 비교하고, 자신에게 맞는 모임을 선택한다.

## 목표 흐름 초안

```text
모임 탐색 → 후보 비교 → 운영 약속 확인 → 참여 조건 확인 → 참여 결정
```

## 개선 대상

### 1차 대상

- 모임 목적과 실제 활동을 비교하기 어려운 문제
- 진행 방식·참가자 구성·음주·촬영·연령 조건이 흩어진 문제
- 비용·취소 조건을 참여 전에 판단하기 어려운 문제

### 후속 대상

- 문제 발생 후 신고·환불·퇴출 처리
- 호스트 운영 포맷 입력과 운영 이력 관리
